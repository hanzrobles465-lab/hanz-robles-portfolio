## How To View The Portfolio

Open `index.html` in a browser.

## How To Run Nihon Job Finder

Server:

```bash
cd nihon-job-finder/server
npm install
npm run dev
```

Client:

```bash
cd nihon-job-finder/client
npm install
npm run dev
```

Create the `.env` files using `.env.example` as reference.

## Security

This repository must not include real `.env` files, private keys or `node_modules`.

If any Supabase key was shared through screenshots or chat, rotate it before publishing the project.
